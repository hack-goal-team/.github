# hack-goal-team

Пилотная система предиктивной аналитики инженерной инфраструктуры для
диспетчерской службы «Москоллектор».

- [`backend`](https://github.com/hack-goal-team/backend) — API, приём событий и PostgreSQL.
- [`frontend`](https://github.com/hack-goal-team/frontend) — интерфейс диспетчера.
- [`ml`](https://github.com/hack-goal-team/ml) — сервис инференса и повторное обучение.

Инструкция по сборке одного ZIP-пакета для локального запуска находится в
[репозитории `.github`](https://github.com/hack-goal-team/.github/tree/main/demo).
Для передачи жюри команда собирает архив; жюри не требуется доступ к
приватным репозиториям.
