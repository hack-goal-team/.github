# Локальный запуск «Москоллектор»

Этот архив содержит исходный код бэкенда, фронтенда и сервиса инференса из
веток `main`, а также один `compose.yaml`. Состав версий записан в
`SOURCES.txt`. Доступ к приватным GitHub-репозиториям для запуска архива не
нужен.

## Требования

Установите Docker Desktop или Docker Engine с Compose v2. На время сборки
нужен доступ в интернет: Docker загрузит базовые образы, Gradle, npm и pip —
зависимости. Выделите Docker не менее 8 ГиБ RAM и 15 ГиБ свободного места
на диске. На ноутбуке должен быть свободен порт 8088.

## Запуск

1. Распакуйте `moscollector-demo.zip` и откройте каталог `moscollector-demo`.
2. Выполните:

   ```bash
   docker compose up --build -d
   docker compose ps
   ```

3. Дождитесь ответа `UP` на `http://localhost:8088/health`. Первый запуск
   включает компиляцию Java, сборку Vue и загрузку зависимостей Python.
4. Откройте `http://localhost:8088/` и войдите как `dispatcher` с паролем
   `demo1234`. Учётка предназначена только для локального пакета.

Работают API, интерфейс, PostgreSQL, Kafka, имитаторы реестра и ОДС, а также
отдельный процесс инференса. Реестр из пакета содержит четыре канала и
загружается через API бэкенда после старта. Исторического журнала в пакете
нет, поэтому прогнозы появятся только после подачи событий; пустой журнал
сразу после запуска ожидаем. Пакет не запускает обучение модели.

## Проверка и остановка

```bash
docker compose ps
docker compose logs --tail=100 backend inference inference-setup
docker compose down
```

`docker compose down` сохраняет данные в томах. Для полного сброса локальных
данных выполните `docker compose down -v`.

На ноутбуке открыт только `127.0.0.1:8088`; PostgreSQL, Kafka и Java-порт
доступны лишь контейнерам. Пароли в этом пакете демонстрационные. Не
разворачивайте его как публичный стенд.
