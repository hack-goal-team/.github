# Репозиторий команды hack-goal-team

Единый пакет для запуска решения на Windows, macOS и Linux находится в
[demo/](demo/README.md). Команда с доступом к приватным репозиториям собирает
один ZIP-архив:

```bash
./demo/make-package.sh
```

Скрипт берёт текущие `main` репозиториев `backend`, `frontend` и `ml`,
записывает их commit SHA в `SOURCES.txt` и создаёт
`moscollector-demo.zip`. В архиве нет Git-истории, секретов стенда и полной
исторической выгрузки. Жюри достаточно передать этот архив и инструкцию
внутри него; доступ к приватным GitHub-репозиториям не требуется.

Для сборки нужны `git`, `tar`, Python 3 и доступ к репозиториям организации.
